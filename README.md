# 慢慢来 · 个人生活手记

一个适合手机和电脑的轻量日常记录网站。每天做了什么就勾选一下，把精力留给一件重要的事。

## 功能

- 健身、吃饭、9点睡觉、补剂、护肤、喝水、开发小游戏：七项每日勾选，按日期保存，可取消。
- 固定支出：月付、年付项目各填一次金额；实际取消服务后勾选“已取消”，从未来预计中排除，取消勾选可恢复。下个月只汇总仍在用的月付，明年预计为月付 × 12 + 年付，同时显示已砍掉的年化开销。可编辑或移除误录项目，金额按整数分保存，状态纳入备份。
- 旧版逐笔花销原样保留在折叠记录中，不自动转成固定支出。需要的旧条目可手动加入固定清单，同一条不会重复加入。
- 两个月行动期：2026-10-17 开始，2026-12-17 复盘。
- 今日重点、能量记录、可选的生活明细、日记与历史回顾。
- 目标栏：收拾房间、2026 年 11 月考取健身教练证书可勾选完成；小游戏上架目标为 10 个，可增减或直接填写数量，达到 10 个自动标记完成。进度长期保存，支持备份恢复。
- TK 平台小游戏清单：taprush、TKCarSurvival、pinrush。完成后直接勾选，状态长期保留，支持取消和备份恢复。
- 原有项目步骤与专注计时保留在“步骤与专注（可选）”。
- JSON 备份导出与导入。

## GitHub Pages

本项目是原生 HTML、CSS 和 JavaScript，不需要安装依赖或构建。

在仓库 Settings → Pages 中选择 Deploy from a branch，发布 `main` 分支的 `/ (root)` 目录。`.nojekyll` 会让 GitHub 直接发布这些静态文件。

## iPhone 主屏幕

用 Safari 打开发布后的网址，点击分享 → 添加到主屏幕。重新添加时请使用新网址。

## 数据与迁移

网页和源码公开，个人生活记录不会上传到 GitHub 仓库。每次修改先保存在当前浏览器，普通刷新会保留；多个页面的不同修改会合并，保存失败会明确提示。

云端使用 Supabase Auth 和 PostgreSQL。完成项目配置后，在「设置 → 记录同步」创建或登录账户，再选择合并本机记录或读取已有云端记录。只有服务器确认保存后才显示「已同步到云端」。手机和电脑登录同一账户即可读取同一份记录；网络异常时保留本机修改并重试。未登录或尚未开启同步时仍只有本机保存。

数据库通过行级权限隔离每个账户的记录，写入使用服务器版本号避免整份覆盖。不同字段合并；同一个字段同时修改时，以当前待提交的修改为准。云端保存最新完整快照，不代替历史备份。

`cloud-config.js` 只放项目公开 URL 和 Publishable key。数据库密码、Secret/service_role key、登录 token 和个人备份禁止提交到公开仓库。Supabase 免费项目长期不活跃可能暂停，可在后台恢复。

未同步的旧网址记录不会自动迁移。先在旧站「设置」中导出 JSON 备份，再在新站导入并开启同步。导入会替换现有数据，并先下载当前数据的备份。请勿把个人备份提交到此公开仓库。

## 本地运行

在此目录运行 `python -m http.server 4173`，打开 `http://localhost:4173/`。

所有资源使用相对路径，支持 GitHub Pages 仓库子目录。首次加载需要联网；当前版本不提供离线缓存。
