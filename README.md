# 慢慢来 · 个人生活手记

一个适合手机和电脑的轻量日常记录网站。每天做了什么就勾选一下，把精力留给一件重要的事。

## 功能

- 健身、吃饭、睡觉、补剂、护肤、喝水、开发小游戏：七项每日勾选，按日期保存，可取消。
- 两个月行动期：2026-10-17 开始，2026-12-17 复盘。
- 今日重点、能量记录、可选的生活明细、日记与历史回顾。
- TK 平台小游戏清单：taprush、TKCarSurvival、pinrush。完成后直接勾选，状态长期保留，支持取消和备份恢复。
- 原有项目步骤与专注计时保留在“步骤与专注（可选）”。
- JSON 备份导出与导入。

## GitHub Pages

本项目是原生 HTML、CSS 和 JavaScript，不需要安装依赖或构建。

在仓库 Settings → Pages 中选择 Deploy from a branch，发布 `main` 分支的 `/ (root)` 目录。`.nojekyll` 会让 GitHub 直接发布这些静态文件。

## iPhone 主屏幕

用 Safari 打开发布后的网址，点击分享 → 添加到主屏幕。重新添加时请使用新网址。

## 数据与迁移

网页和源码公开；你填写的生活记录只保存在当前浏览器的 localStorage，不会上传到 GitHub，也不会自动跨设备同步。

换网址或浏览器后，旧数据不会自动出现。先在旧站「设置」中导出 JSON 备份，再在新站导入。导入会替换现有数据，并先下载当前数据的备份。请勿把个人备份提交到此公开仓库。

## 本地运行

在此目录运行 `python -m http.server 4173`，打开 `http://localhost:4173/`。

所有资源使用相对路径，支持 GitHub Pages 仓库子目录。首次加载需要联网；当前版本不提供离线缓存。
